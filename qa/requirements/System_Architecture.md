# FoodOrder - System Architecture

## 1. Architecture Overview

FoodOrder follows a three-tier web application architecture.

The three main layers are:

1. Frontend
2. Backend API
3. Database

## 2. Technology Stack

### Frontend
- React
- Vite
- Tailwind CSS

### Backend
- Node.js
- Express.js
- REST API

### Database
- PostgreSQL

### Quality Engineering
- Postman
- Java
- Selenium WebDriver
- TestNG
- Maven
- SQL
- GitHub Actions

## 3. Application Flow

Customer/Admin
    ↓
React Frontend
    ↓
REST API
    ↓
Node.js + Express
    ↓
PostgreSQL Database

## 4. Main Modules

### Customer
